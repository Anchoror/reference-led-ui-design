# 排版关系与浏览节奏

处理中文或其他语言适配、信息流重设计、单列/双列等布局比较时读取。这里给出判断方法，不规定所有列表都用双列、去摘要、禁圆角或使用某种字体。

## 参考中的关系怎样迁移

先找出参考成立的关系：标题实际占据的宽度和重量、标题与正文的字形差异、文字形成的面积、图片内部主体尺度、明暗与方向，以及组内/组间空白。字号、圆角和间距符合，不代表整体已经成立。

- 英文窄体换成短中文页名时，同时判断字面面积、行长与控件的主次；不压扁汉字模仿品牌字形，也不只把字号换成近似值。
- 连续摘要换成话题、作者和互动后，原来完整的文字块可能变成几行碎信息。重新组织现有字段，避免直接继承原间距；也不能为了填满文字区就自动补摘要或假内容。
- 图像去掉外框后，会承担更多页面性格。检查裁切后的主体尺度、方向与反差；区分摄影选择带来的效果与布局自身的贡献。

观察结果、适配提案和实际验证分开说明。需要改变参考的居中方式、列数或图像比例时，指出当前冲突、保留的关系及代价，不能把新增处理说成原作规则。

## 先明确使用任务

区分用户是在发现/比较内容、阅读正文、填写信息还是完成操作。品牌编辑页可以提供排版依据，但其慢读节奏不能直接替代公开笔记流的发现任务。

列表的阅读单元应围绕当前判断需要组织，不按固定的“标题＋摘要＋作者”模板补齐。作者、话题和反馈等社区信息是否出现、怎样分组，要结合已有产品能力；正文可留在详情，但这不是所有列表必须去摘要的规定。

图片在列表中是兴趣预览还是完整观看对象，也要明确。完整竖图、有限裁切、受控预览比例各有代价：主体识别、单条高度、连续发现机会与详情连续性。用实际素材验证，不自动要求每张图完整显示或假装拥有主体识别/焦点数据。

空间动效需要兼顾操作频率与内容连续性；不能只为展示参考，让高频浏览反复经历与任务不相称的等待。是否采用完整翻面或较轻的物件接续，依据当前任务判断。

## 布局方案怎样公平比较

比较列数或密度时，尽量共用内容、推荐顺序、照片、字段、字体、视口与功能，只改变所研究的变量。若方案本来就要改变多项因素，明确这些差异，不把信息量不同的旧稿/新稿当成仅比较列数的实验。

连续查看多屏、必要时滚到全部样例末尾，检查横图、竖图、弱主体照片、长标题/作者和缺省内容。观察一屏中怎样接触新内容、图像细节、文字可读、触控区域及打开/返回位置，不能只看首屏或挑选最漂亮的素材。

可提供独立滚动、相同像素滑距、定位同一条等不同比较方式；说明它们分别回答什么问题。不要把百分比同步称为同内容对齐，也不要重复数据、增加假空白或循环回头来伪造相同滚动范围。临近末尾无法顶对齐时，保留真实边界并说明。

更高密度、更短列表、无圆角或有动效都不是质量结论。把可见效果、损失与未测项目放在一起，让选择回到真实使用任务；不从浏览器样例推断转化率或真机性能。

## 认可与公开范围

按用户最新反馈判断哪些版本可作为案例。认可比较草稿，不自动等于选定某种列数、批准全局视觉规范或完成产品上线；公开案例还需要对应发布授权。被后续否定的旧稿不能继续用早期认可包装成成功案例。
